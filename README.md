# HN-KS26-CNTT1_Nhap-mon-CNTT_Session22_Ex01

Toán tử để tìm giáo trình "Nhập môn Công nghệ Thông tin" bản PDF của Học viện để ôn thi như sau:

```text
"nhập môn công nghệ thông tin" filetype:pdf site:ptit.edu.vn -site:cuuduongthancong.com -site:weebly.com
```

Từng mảnh trong combo làm gì:

- `"nhập môn công nghệ thông tin"`: ngoặc kép khoá nguyên tên giáo trình, Google chỉ tìm đúng cụm này chứ không tách từ rời ra đoán mò
- `filetype:pdf`: chỉ nhận kết quả là tệp PDF thật, loại hết các trang web bình thường
- `site:ptit.edu.vn`: giới hạn tìm trong máy chủ của Học viện, ra đúng tài liệu chính thống phía trường đăng
- `-site:tailieu.vn -site:123docz.net`: dấu trừ tống khứ hai trang rác hay trôi nổi nhất trong kết quả, chúng thường bắt đăng nhập hoặc nạp thẻ mới cho tải

Vì sao filetype: tiết kiệm thời gian hơn gõ kiểu "tải sách...": gõ "tải sách nhập môn công nghệ thông tin" thì Google hiểu mình muốn đọc bài viết, trả về hàng loạt trang trung gian ép like, ép đăng nhập, quảng cáo loè loẹt, chưa kể nút TẢI XUỐNG giả mạo dính mã độc là chuyện thường. Mình phải bấm từng link để sàng lọc thủ công mà cái tải về chưa chắc đã là file sách. Có filetype:pdf thì Google chỉ đưa file PDF gốc, nhìn đường link phát biết ngay đuôi .pdf, bấm vào là tải thẳng file về máy, khỏi qua cò trung gian, khỏi sợ bấm nhầm nút quảng cáo.
